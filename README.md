# Malinalli Talent Hub

Crea una aplicación web responsiva de Reclutamiento y Selección (ATS / Portal de Empleo) para la empresa 'Malinalli' usando React y Tailwind CSS. Utiliza la paleta corporativa: fondo principal en café oscuro/casi negro (#1C0D0A), contenedores de tarjetas en café cálido y amarillo dorado (#F5B800) para los botones de acción principal (CTA), pestañas activas y elementos destacados. Incluye una barra de navegación superior con el logo y dos vistas principales: 1) Portal público de vacantes para candidatos y 2) Panel de control interno de RH con un tablero Kanban de 5 columnas (Postulado, Filtro, Entrevista, Oferta, Contratado), adjunto imagenes de referencia del diseño.
